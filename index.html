1. 수집하는 정보

ShieldVPN은 어떠한 개인정보도 수집하지 않습니다. 앱 사용 로그, 검색 기록, IP 주소를 저장하지 않습니다.

2. VPN 연결

ShieldVPN은 WireGuard 프로토콜을 사용하여 암호화된 VPN 연결을 제공합니다. 사용자의 인터넷 트래픽은 저장되거나 모니터링되지 않습니다.

3. 제3자 공유

ShieldVPN은 사용자 데이터를 제3자와 공유하지 않습니다.

4. 보안

AES-256 암호화와 WireGuard 프로토콜을 사용하여 사용자의 인터넷 연결을 보호합니다.
